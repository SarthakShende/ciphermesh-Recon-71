# --- GPIO (DHT22) ----------------------------------------------------------
#
# Bit-banging the DHT22 single-wire protocol needs a GPIO backend. The
# installer resolves these at install time, in this order:
#
#   1. lgpio              (pip wheel; aarch64 wheels exist for cp39-cp312 ONLY)
#   2. python3-lgpio      (apt, Raspberry Pi OS archive only; not in Debian)
#   3. /dev/gpiochip0     (pure-python ioctl binding shipped with ciphermesh,
#                          zero dependencies, always available on kernel >= 5.x)
#
# NOT listed as a hard dependency: "lgpio" has no cp313/cp314 wheel, so a
# Raspberry Pi OS Trixie install would attempt a source build. ciphermesh
# falls back to the pure-python gpiochip backend instead of failing.
# See docs/sensor.md.
